#  Analyse de Données Humanitaires — Burkina Faso

> **Projet de Data Analysis | DIALLO Alimou — Data Analyst **

---

##  Présentation du projet

Ce projet regroupe une série de travaux pratiques d'analyse de données
basés sur des datasets réels concernant le Burkina Faso.

Les données proviennent d'organisations humanitaires internationales
(WFP, IDMC, OCHA) et couvrent des thématiques cruciales pour
comprendre la situation humanitaire au Burkina Faso.

> *"Ces données représentent des réalités humaines.
> L'analyse de données au service de l'humanitaire."*
